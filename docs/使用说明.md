# 赛博拼豆使用说明

## 一分钟启动

下载 Releases 的 `SaiboPindou-v1.0.0-Windows.zip`，解压后双击 `启动赛博拼豆.exe`。

```text
赛博拼豆/
├─ 启动赛博拼豆.exe       ← 双击这个
├─ 使用说明.txt
└─ bead-room/
   └─ dist/              ← 游戏、库和材质，必须保留
```

启动器只在本机 `127.0.0.1:4173` 提供服务，默认浏览器会打开游戏。准备好后可以反复点击启动器重新进入。

## 四个页面

- **工作室**：继续创作、开始新作品、选图纸、查看草稿。
- **创作台**：选颜色放豆；鼠标滚轮缩放，移动工具平移；手机使用触控手势。
- **制作图纸**：导入自己的图片，设置尺寸与颜色，生成并保存。图纸可在工作室选择，用作蓝图或参考。
- **收藏室**：旋转房间；选择作品查看、调整位置；「样式」设置墙面与地板。

完成作品后，按照页面步骤熨烫与脱板，选择钥匙扣或立牌，再选择收藏位置。

## 常见问题

**下载哪个文件？**

下载带 `Windows.zip` 的发布附件。`Source code` 是开发源码，单独下载它不能直接双击 EXE 运行。

**点开说找不到游戏文件？**

先完整解压，确认 EXE 与 `bead-room` 文件夹处在同一目录。不要在压缩包内运行，也不要单独移动 EXE。

**端口 4173 已被占用？**

如果托盘里有旧的拼豆后台，先使用它的「退出后台服务」，再运行当前版本。其他程序占用时，请先结束其对应的本地服务。

**关闭浏览器以后怎么再进入？**

再次双击启动器。退出整个后台可以使用任务栏通知区域里的拼豆托盘菜单。

**数据保存在什么地方？**

保存在同一电脑、同一浏览器对该本地地址的网站存储中。清除网站数据、更换浏览器或使用临时模式会影响保存。应用目前没有云端账号同步。

**自动铺满为什么要密码？**

这是现有设计保留的辅助功能限制；普通手动创作不需要密码。开发者应注意：它是浏览器端的功能开关，不是服务器身份验证。

**能在手机上用吗？**

网页布局支持触屏，但本次 Windows ZIP 是给 Windows 电脑使用的，不是 Android APK 或 iOS 安装包。启动器默认只允许本机访问。

## 开发结构

```text
bead-room/dist/          网页应用源码与本地静态资源
bead-room/launcher/      C# 无控制台启动器源码与图标
bead-room/server.mjs     Node.js 开发静态服务
scripts/build-windows.ps1  Windows 构建、免安装打包与 SHA256
docs/                   使用说明与截图
```

构建要求 Windows 的 .NET Framework 4.x 编译器与 PowerShell。网页开发可使用 Node.js；发布的 Windows 包不依赖 Node.js。
